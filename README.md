## Prerequisites
 
1. **Docker Installation**  
   Ensure that you have Docker installed on your system. For Ubuntu, follow [Docker's official install guide](https://docs.docker.com/desktop/install/ubuntu/).
 
2. **NVIDIA GPU & Drivers**  
   This project requires a machine with an NVIDIA GPU. Make sure you have the appropriate NVIDIA drivers installed.
 
3. **NVIDIA Container Toolkit (nvidia-docker)**  
   To enable GPU support within Docker containers, install the NVIDIA Container Toolkit. Once installed, you can run containers with GPU support by adding the ```--gpus all``` flag.
